# Udemy Clone

A responsive **Udemy-inspired course website UI** built using **HTML and CSS**, with **CSS Flexbox** used to create flexible and responsive layouts.

This project was created as a frontend practice project to improve my skills in structuring web pages, styling components, and creating layouts using Flexbox.



## 📌 Features

* Udemy-inspired homepage design
* Navigation bar with logo and menu items
* Search bar
* Course categories section
* Course cards with images, titles, ratings, and pricing
* Responsive Flexbox-based layouts
* Clean and simple user interface
* Hover effects for interactive elements

## 🛠️ Technologies Used

* **HTML5** – Page structure and semantic elements
* **CSS3** – Styling and visual design
* **CSS Flexbox** – Layout and alignment
* **Google Fonts** – Typography
* **Font Awesome** – Icons
